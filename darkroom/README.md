Darkroom is the Photography reference theme for Sites, with schema-complete placeholder sections for Mara Lindqvist’s documentary practice. Create the workspace content type `series` with `year`, `location`, `statement` (richtext), `cover` (image), `cover_alt`, `photos` (gallery) and `edition_note`, then bind `/work/:series` to the `series` template; fixture records demonstrate this contract. Run `npm install`, `sites check .` and `sites dev .`; replace the twelve SVG studies and demonstration copy before publishing. Section markup follows in D2.
