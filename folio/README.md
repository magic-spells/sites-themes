Folio is a journal theme for essays on walking, weather and small towns. This 0.1.0 schema layer defines the editor settings, design tokens and The Slow Mile fixtures; section markup, components and styling follow in D2. The posts content type uses topic, date, author, reading_minutes, standfirst, image, image_alt and body, with optional image_caption. Newsreader roman and italic are redistributed under the adjacent OFL-Newsreader.txt; IBM Plex Mono loads from Google.
